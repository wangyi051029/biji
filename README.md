## 二、快速开始

```bash

pip3 install -r requirements.txt

# 2. 初始化演示数据（预处理全部子集 + 训练模型 + 智能优化，约 20 秒）
python3 -m backend.seed

# 3. 启动系统
python3 -m uvicorn backend.main:app --host 0.0.0.0 --port 8000
# 浏览器访问 http://127.0.0.1:8000

# 或一键启动（含初始化）
./run.sh
```

运行自动化测试：

```bash
python3 -m pytest        # 28 项测试全部通过
# 或 ./run_tests.sh
```

## 三、系统功能

系统前端包含六大页面，走通"数据 → 建模 → 优化 → 预测 → 对比"完整业务闭环：

1. **总览**：系统指标卡片、特征筛选柱状图、模型推理耗时对比图；
2. **数据管理**：对 C-MAPSS 子集执行统计学习预处理（清洗/噪声识别/特征筛选/划分/交叉验证）、查看数据集与特征详情；
3. **模型训练**：配置超参数训练 LSTM 深度学习模型；
4. **智能优化**：对模型实施剪枝 + 量化，雷达图对比压缩效果；
5. **在线预测**：输入发动机单元号，预测剩余寿命 RUL 并记录；
6. **对比分析**：基准模型 vs 优化模型指标对比。

## 五、数据说明

本项目使用 **NASA C-MAPSS 涡扇发动机退化数据集**（公开工业时序数据），详见 [`data/数据来源说明.md`](data/数据来源说明.md)。

| 子集 | 训练单元 | 测试单元 | 原始传感器 | 预处理后特征 |
|------|---------|---------|-----------|------------|
| FD001 | 100 | 100 | 21 | 14 |
| FD002 | 260 | 259 | 21 | 4 |
| FD003 | 100 | 100 | 21 | 14 |
| FD004 | 248 | 249 | 21 | 6 |

预处理流程（统计学习方法）：数据清洗 → 噪声识别（IQR+Z-score）→ 特征筛选（方差+相关+ANOVA）→ 分段线性 RUL 标签 → 按单元划分 train/val/test → GroupKFold 5 折交叉验证 → 标准化（仅训练集拟合防泄漏）。详见 [`data/数据预处理说明.md`](data/数据预处理说明.md)。

## 六、实验结论（FD001 演示）

| 指标 | 基准模型（LSTM） | 优化后（剪枝30%+int8量化） | 变化 |
|------|----------------|--------------------------|------|
| 参数量 | 121.03 K | 85.23 K | **-29.6%** |
| 模型大小 | ~484 KB | ~85 KB | **-82.4%** |
| MAE | 12.06 | 10.33 | 精度保持 |
| 推理耗时 | 0.06 ms | 0.13 ms | 量级相同 |

> 结论：剪枝+量化在几乎不损失精度的前提下，实现参数量减少约 30%、存储减少约 82%，验证了融合方案降低算力开销、适配普通 PC 的目标。
