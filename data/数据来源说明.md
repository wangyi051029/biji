# 数据来源说明

## 数据集名称

NASA C-MAPSS 涡扇发动机退化仿真数据集（Turbofan Engine Degradation Simulation Data Set）

## 数据集简介

C-MAPSS 是 NASA 提供的商用模块化航空推进系统仿真（Commercial Modular Aero-Propulsion System Simulation）数据，模拟涡扇发动机从正常状态到故障（退化）的完整生命周期运行过程，是故障预测与健康管理（PHM）领域 RUL 预测的经典公开基准数据集。

- **数据规模**：约 44 MB（zip 压缩后），包含 4 个子集 FD001~FD004；
- **数据内容**：每台发动机含 3 个运行设置参数 + 21 路传感器测量（温度、压力、转速等），按运行循环（cycle）记录；
- **任务目标**：根据历史运行数据预测发动机剩余使用寿命（RUL）；
- **小样本特性**：每个子集训练单元仅 100~260 台，天然符合"小样本工业工况预测"选题；
- **含噪声**：数据混有传感器噪声，契合统计学习方法的数据处理需求。

## 数据文件

原始数据存放于 `data/raw/` 目录，每个子集 3 个文件：

| 文件 | 说明 |
|------|------|
| `train_FD00X.txt` | 训练数据（含 RUL 标签） |
| `test_FD00X.txt` | 测试数据（不含标签） |
| `RUL_FD00X.txt` | 测试集每台发动机的真实 RUL 标签 |

## 数据使用说明

本项目将四子集全部用于系统演示与实验：FD001/FD003 为单工况（保留 14 特征），FD002/FD004 为多工况（保留 4/6 特征）。数据经统计学习预处理后存入 `data/processed/`，详见 `data/数据预处理说明.md`。
