# 数据预处理说明

本项目采用**统计学习方法**完成 C-MAPSS 数据的预处理，预处理程序为 `code/preprocess.py`（独立脚本）与 `backend/algorithms/statistical.py`（系统内统计学习模块），两者逻辑一致。

## 预处理流程

```
原始数据(data/raw)
   │ 1. 数据清洗：缺失值检测、常值/近常值传感器剔除
   │ 2. 噪声识别：IQR 准则 + Z-score 准则（仅标记不删除）
   │ 3. 特征筛选：低方差剔除 → 高相关冗余剔除 → 单因素 ANOVA 显著性检验
   │ 4. 标签构造：分段线性 RUL（上限 125）
   │ 5. 数据划分：按发动机单元划分 train/val/test（防泄漏）
   │ 6. 交叉验证：GroupKFold 5 折（同机不跨折）
   │ 7. 标准化：StandardScaler 仅训练集拟合
   ▼
预处理结果(data/processed)
```

## 各步骤说明

### 1. 数据清洗
- 缺失值检测：遍历检查 NaN，本项目数据无缺失值；
- 常值剔除：计算每列方差，剔除方差为 0 的常值传感器（如 FD001 剔除 s1/s5/s10/s16/s18/s19）。

### 2. 噪声识别
- **IQR 准则**：`Q1 - 1.5*IQR` 与 `Q3 + 1.5*IQR` 之外的样本标记为异常；
- **Z-score 准则**：`|z| > 3` 的样本标记为异常；
- 仅统计标记，不删除，作为数据质量指标记录（FD001 噪声率 5.93%）。

### 3. 特征筛选（三层递进）
1. **低方差剔除**：标准化后剔除方差过低的传感器（无信息量）；
2. **高相关剔除**：剔除相关系数 |r| > 0.95 的冗余传感器；
3. **ANOVA 检验**：单因素方差分析，保留与 RUL 显著相关的特征（p < 0.05）。

筛选结果（特征数）：FD001→14，FD002→4，FD003→14，FD004→6（与 PHM 领域标准一致）。

### 4. RUL 标签构造
采用**分段线性函数**：`RUL = min(max_cycle - cycle, 125)`，即寿命上限 125 个循环，避免早期样本标签过大影响训练。

### 5. 数据划分
按发动机单元（unit）划分，每台单元最后 20% 周期作为测试集，15% 单元作为验证集，其余作为训练集，确保同一单元数据不跨集合（防数据泄漏）。

### 6. 交叉验证
GroupKFold 5 折，按单元分组，同一发动机的数据只出现在同一折，保证验证可靠性。

### 7. 标准化
StandardScaler 仅在训练集上拟合，再应用到验证/测试集，防止数据泄漏。

## 预处理结果

| 子集 | 原始传感器 | 筛选后特征 | 训练样本 | 验证样本 | 测试样本 | 噪声率 |
|------|----------|-----------|---------|---------|---------|--------|
| FD001 | 21 | 14 | 14024 | 2444 | 4163 | 5.93% |
| FD002 | 21 | 4 | 36651 | 6254 | 10854 | 15.9% |
| FD003 | 21 | 14 | 16825 | 2910 | 4985 | 15.3% |
| FD004 | 21 | 6 | 42004 | 6899 | 12346 | 15.4% |

验证结果：四个子集均无缺失值、标准化后均值≈0、方差≈1，符合预期。

## 输出文件

`data/processed/` 下每个子集包含：

| 文件 | 说明 |
|------|------|
| `train_clean.csv` / `val_clean.csv` / `test_clean.csv` | 预处理后数据（含 unit/cycle/RUL） |
| `feature_selection.json` | 特征筛选过程与结果 |
| `cv_folds.json` | 交叉验证划分结果 |
| `scaler.json` | 标准化参数 |
| `preprocess_summary.json` | 汇总指标（规模/噪声率/特征等） |

## 复现方式

```bash
# 全量预处理（将 data/raw → data/processed）
python3 code/preprocess.py

# 或通过系统一键初始化（含预处理+训练+优化）
python3 -m backend.seed
```
