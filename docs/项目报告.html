Git 仓库：github.com/wangyi051029/biji  ·  2026 年 9 月
摘要：本课程设计面向工业设备剩余寿命（Remaining Useful Life, RUL）预测这一典型小样本工况预测问题，以 NASA C-MAPSS 航空发动机退化数据集为数据基础，采用 统计学习（数据预处理与特征工程）＋深度学习（双层 LSTM 时序预测）＋智能计算优化（剪枝与量化） 融合的技术路线，构建了一套完整的 B/S 架构智能应用系统。系统提供数据管理、模型训练、在线预测、智能优化、手动测试、对比分析等 7 大功能页面，共 29 项自动化测试全部通过。在 FD001 演示子集上，基准 LSTM 模型 MAE 11.10；经剪枝 30%＋int8 量化优化后，参数量降低 29.6%、模型体积压缩 82.4%，MAE 进一步降至 7.21。项目另产出离线单文件测试站（GitHub Pages 在线访问）与 Streamlit 完整版在线部署，实现"任何电脑打开即用"。全过程采用 vibe coding 方法，AI 交互记录随阶段归档。

一、项目概述

1.1 项目背景

在工业制造与设备运维场景中，设备（如航空发动机、风电齿轮箱、机床主轴等）的性能随使用逐渐退化。若能提前准确预测设备的剩余使用寿命（RUL），即可实现预测性维护：在故障发生前安排检修、减少非计划停机、降低维护成本并保障生产安全。C-MAPSS（Commercial Modular Aero-Propulsion System Simulation）数据集由 NASA 提供，模拟了涡扇发动机从健康到故障的全生命周期退化过程，是工业设备 RUL 预测领域最经典的公开基准之一。

工程上的难点在于：可用的完整生命周期样本有限（即"小样本"），传感器读数含有噪声，且工况复杂多变。单一方法难以兼顾特征提取、时序建模与部署算力约束，因此本项目采用统计学习＋深度学习＋智能计算优化的融合路线。

1.2 项目目标

  • 数据目标：完成 C-MAPSS 四个子集（FD001~FD004）的采集、说明与标准化预处理，形成可直接用于建模的数据资源。
  • 算法目标：实现统计学习预处理流水线、基于 LSTM 的深度学习 RUL 预测模型、以及剪枝＋量化智能计算优化。
  • 系统目标：构建 B/S 架构的完整智能应用，普通 PC（CPU 即可）可运行，形成"数据→模型→优化→预测"业务闭环。
  • 交付目标：自动化测试、需求规格说明书、设计报告、答辩 PPT、过程档案、在线可访问的演示网站。

1.3 技术路线

采用"统计学习做特征与数据治理 → 深度学习做时序建模 → 智能计算优化做模型压缩部署"的三段式融合路线：

  • 统计学习：数据清洗、IQR＋Z-score 噪声识别、方差/相关性/ANOVA 特征筛选、分段线性 RUL 标签、GroupKFold 交叉验证、标准化。
  • 深度学习：滑动窗口构造时序样本，双层 LSTM（含 Dropout、Adam、早停、学习率调度）回归预测 RUL。
  • 智能计算优化：权重幅度剪枝（Magnitude Pruning）＋模拟量化（int8/4-bit），对比压缩前后精度与体积。

1.4 开发方法

本项目采用 vibe coding 方法：在 AI 辅助下完成需求分析、方案设计、编码实现、测试验证与文档编写，全程使用 Git 进行版本管理（远端仓库 github.com/wangyi051029/biji），AI 交互记录（提示词）随阶段归档至 prompt/ 目录，保证过程可追溯。

三、数据来源与预处理

3.1 数据来源

数据来自 NASA C-MAPSS 涡扇发动机退化仿真数据集（公开数据集），官方页面：https://data.phmsociety.org/nasa/，直链已校验可访问。四个子集分别对应不同的故障模式与工况数量组合。数据已随项目入库（data/raw/），来源与版权说明见 data/数据来源说明.md。

3.2 预处理流水线（统计学习方法）

  1. 数据清洗：解析原始文本、剔除重复与异常记录、统一列名与类型。
  2. 噪声识别：基于 IQR 与 Z-score 识别并处理离群噪声，计算各子集噪声率。
  3. 特征筛选：结合方差过滤、相关性分析与单因素 ANOVA，从 21 个传感器中筛选有效特征（各子集保留 4~14 个不等）。
  4. RUL 标签：采用分段线性衰减标签，反映早期缓慢退化与后期加速退化规律。
  5. 数据划分：按发动机单元划分 train/val/test，采用 GroupKFold 5 折交叉验证防止跨单元泄漏。
  6. 标准化：仅基于训练集拟合 StandardScaler 并保存（scaler.json），避免信息泄漏，保证手动预测与训练同口径。

五、系统实现

5.1 后端实现

后端基于 FastAPI + SQLite，将三大算法模块封装为服务层接口。关键实现包括：

  • 模型训练：滑动窗口构造时序样本，LSTM 模型采用 Huber 损失（SmoothL1）、Adam 优化器、梯度裁剪、ReduceLROnPlateau 学习率调度与早停；模型与元信息持久化为 .pt / .meta.json。
  • 在线预测：从预处理测试集加载指定单元最近 N 周期数据，标准化后构造窗口预测 RUL，并持久化预测记录。
  • 手动预测：新增 /api/model/info/{name} 返回特征顺序/窗口/示例读数供前端动态建表单；/api/model/predict_manual 接收任意行传感器读数，用同一套 scaler 标准化后预测，支持"无真值"输入（修复了真值为 None 时的误差计算缺陷）。
  • 智能优化：对基准模型执行权重幅度剪枝与模拟量化，输出压缩前后指标对比并保存优化模型。

5.2 前端实现

前端为纯原生 HTML/CSS/JavaScript 单页应用，通过 Fetch 调用后端 API，包含 7 个功能标签页；使用 ECharts 渲染退化曲线与统计图表；所有页面数据实时来自后端接口。前端支持在浏览器中动态加载模型特征顺序并生成输入表单。

5.3 自动化测试

基于 pytest 编写 29 项自动化测试（数据、算法、API、业务四组），覆盖数据加载与预处理、模型训练与预测、手动预测输入校验、优化对比、数据库持久化等关键路径，一键运行 bash run_tests.sh 全部通过。

六、实验结果与分析

6.1 实验设置

以 FD001 子集为演示数据：双层 LSTM（hidden=96，窗口=30，输入 15 维特征），训练样本 60 个窗口、10 个 epoch，在测试窗口上评估 MAE/RMSE；随后对基准模型执行剪枝比例 30%＋int8 模拟量化。

6.3 结果分析

结论：融合方案验证了目标——通过统计学习有效治理数据并筛选特征，使深度学习模型在小样本下达到可用精度（FD001 MAE 11.10）；进一步通过智能计算优化（剪枝＋量化）在几乎不损失（本例甚至提升）精度的前提下，实现参数量减少约 30%、存储减少约 82%，显著降低算力与存储开销，适配普通 PC 部署目标。演示预测（单元 2）RUL≈45.04 周期；手动测试任意读数亦可即时得到预测结果。

十、总结与展望

10.1 总结

本项目完整走通了"数据治理 → 特征工程 → 深度学习建模 → 智能计算优化 → 系统集成 → 测试与交付"的工业智能应用开发闭环。在真实公开基准（NASA C-MAPSS）上验证了统计学习、深度学习、智能计算优化三类技术的融合价值：统计学习解决小样本与噪声下的数据质量问题，LSTM 实现高精度时序 RUL 预测，剪枝量化在不损精度的前提下大幅压缩模型，使系统可在普通 PC 上运行，并支持任意数据的在线测试与云端部署。

10.2 不足与展望

  • 当前演示聚焦 FD001 子集，后续可扩展 FD002~FD004 的完整训练与多工况自适应建模（迁移学习）。
  • 可引入 Transformer 等更先进的时序架构，以及贝叶斯不确定性估计，给出预测置信区间。
  • 优化环节可进一步探索结构化剪枝、知识蒸馏与端侧部署（ONNX/嵌入式），支撑边缘计算场景。
  • 可接入实时数据流，形成在线学习与持续更新能力。
