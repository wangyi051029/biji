# 设备工况智能预测系统 —— 需求规格说明书

## 1. 引言

### 1.1 编写目的
本文档面向《制造智能技术》课程设计，定义"设备工况智能预测系统"的功能、非功能需求与验收标准，作为后续设计、开发、测试与答辩的依据。

### 1.2 项目背景
工业设备运维场景中，传感器采集大量设备运行时序数据，但故障标签样本稀缺、数据含噪声，普通 PC 算力有限。本系统针对**小样本工业工况预测**问题，融合统计学习、深度学习与智能计算优化三类技术，构建一套可运行于普通 PC 的 B/S 架构 demo，实现设备工况识别与故障趋势（剩余寿命 RUL）预判。

### 1.3 术语定义
| 术语 | 说明 |
|------|------|
| RUL | Remaining Useful Life，剩余使用寿命（以运行周期计） |
| C-MAPSS | NASA 涡扇发动机退化仿真数据集 |
| 小样本 | 训练样本（发动机单元）数量少（100~260 台） |
| 剪枝 | 删除模型中不重要的连接权重，实现轻量化 |
| 量化 | 将浮点权重压缩为低比特整数，减小存储与计算开销 |

## 2. 用户与场景分析

### 2.1 目标用户
- **设备运维工程师**：通过系统监测设备健康状态，预判故障发生时间，安排预防性维护；
- **课程设计评审**：验证系统架构完整性与技术方向覆盖度。

### 2.2 典型业务场景
1. 工程师上传/选择某台设备的历史传感器数据 → 系统清洗、筛选特征；
2. 系统训练深度学习预测模型，评估预测精度；
3. 系统对模型实施智能计算优化（剪枝+量化），对比优化前后性能；
4. 输入设备最近一段传感器序列 → 系统输出剩余寿命预测值，辅助运维决策。

## 3. 功能需求

### 3.1 数据管理功能（统计学习）
| 编号 | 需求 | 说明 |
|------|------|------|
| F1.1 | 数据预处理 | 对 C-MAPSS 四子集执行清洗、缺失值检测、常值传感器剔除 |
| F1.2 | 噪声识别 | 基于 IQR 与 Z-score 统计法标记异常噪声点 |
| F1.3 | 特征筛选 | 方差分析 + 相关性分析 + 单因素 ANOVA，剔除无效/冗余特征 |
| F1.4 | 数据划分 | 按发动机单元划分训练/验证/测试集，互不泄漏 |
| F1.5 | 交叉验证 | GroupKFold 5 折（按单元分组） |
| F1.6 | 数据入库 | 数据集元信息持久化至 SQLite 数据库 |

### 3.2 模型训练功能（深度学习）
| 编号 | 需求 | 说明 |
|------|------|------|
| F2.1 | 时序样本构造 | 滑动窗口（默认 30 周期）构造训练样本 |
| F2.2 | LSTM 模型 | 双层 LSTM + 全连接回归，输出 RUL 预测 |
| F2.3 | 训练策略 | Adam + 权重衰减、Dropout、早停、学习率调度（ReduceLROnPlateau/余弦退火） |
| F2.4 | 模型评估 | 输出 MAE、RMSE、推理耗时、参数量 |
| F2.5 | 模型持久化 | 模型权重与元信息保存/加载 |

### 3.3 智能计算优化功能（优化智能计算）
| 编号 | 需求 | 说明 |
|------|------|------|
| F3.1 | 模型剪枝 | 权重幅值剪枝，生成稀疏模型 |
| F3.2 | 参数量化 | 浮点 → int8 模拟量化，减小存储与计算 |
| F3.3 | 对比评估 | 优化前后参数量、模型大小、推理耗时、精度对比 |

### 3.4 在线预测功能
| 编号 | 需求 | 说明 |
|------|------|------|
| F4.1 | 在线预测 | 输入发动机最近 N 周期数据，输出 RUL 预测值 |
| F4.2 | 预测记录 | 预测结果（真值/预测值/误差）持久化并展示 |

### 3.5 系统功能
| 编号 | 需求 | 说明 |
|------|------|------|
| F5.1 | B/S 架构 | 前端 Web UI + 后端 REST API |
| F5.2 | 前端界面 | 总览、数据管理、模型训练、智能优化、在线预测、对比分析六大页面 |
| F5.3 | 自动化测试 | pytest 覆盖算法、数据库、API 层 |

## 4. 非功能需求

### 4.1 性能需求
- 普通 PC（无 GPU）可完成全部训练与推理；
- 单次推理耗时 < 10ms（模型 120K 参数）；
- 演示训练（1200 样本 × 35 轮）耗时 < 60 秒。

### 4.2 可靠性需求
- 交叉验证保证结果稳定；
- 自动化测试保障核心功能正确性；
- 数据泄漏防护（按单元划分、缩放仅训练集拟合）。

### 4.3 可用性需求
- 一键启动脚本 `run.sh`；
- 初始化脚本 `backend/seed.py` 自动完成数据/训练/优化。

### 4.4 可维护性需求
- 模块化分层：algorithms / services / database / main；
- 代码含中文注释与文档字符串。

## 5. 数据需求

### 5.1 数据来源
NASA C-MAPSS 涡扇发动机退化数据集（公开数据集），详见 `data/数据来源说明.md`。

### 5.2 数据规模
| 子集 | 训练单元 | 测试单元 | 传感器 | 预处理后特征 |
|------|---------|---------|--------|------------|
| FD001 | 100 | 100 | 21 | 14 |
| FD002 | 260 | 259 | 21 | 4 |
| FD003 | 100 | 100 | 21 | 14 |
| FD004 | 248 | 249 | 21 | 6 |

### 5.3 数据库设计（SQLite）
| 表 | 说明 |
|----|------|
| datasets | 数据集元信息（规模、特征、噪声率） |
| models | 模型记录（参数、压缩状态、指标） |
| predictions | 预测记录（输入、真值、预测值、误差） |
| experiments | 实验记录（配置与指标） |

## 6. 技术方向覆盖映射

| 技术方向 | 系统中的实际作用 | 涉及模块 |
|---------|----------------|---------|
| 统计学习 | 数据清洗、噪声识别、特征筛选、数据集划分、交叉验证 | `backend/algorithms/statistical.py` |
| 深度学习 | 时序深层特征提取、LSTM RUL 预测、反向传播训练 | `backend/algorithms/deep_learning.py` |
| 优化智能计算 | 模型剪枝、参数量化、学习率调度、压缩对比 | `backend/algorithms/optimization.py` |

## 7. 验收标准

1. 系统可在普通 PC 上通过 `python3 -m uvicorn backend.main:app --port 8000` 启动；
2. 前端六大功能页可完整走通业务闭环；
3. 自动化测试全部通过（`python3 -m pytest`）；
4. 实现 ≥3 个技术方向，每个在系统中承担实际功能（非装饰性引入）；
5. 数据可溯源（公开数据集 + 有效链接 + 说明文档）。
