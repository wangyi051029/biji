摘要

本项目面向工业设备剩余使用寿命（RUL）预测这一典型小样本工业场景，采用 vibe coding 方法完成了一整套可交付、可运行、可追溯的智能计算系统。项目融合统计学习（数据清洗、噪声识别、特征筛选、交叉验证）、深度学习（双层 LSTM 时序网络）与智能计算优化（剪枝 + 量化）三大技术方向，在普通 PC（CPU）上构建了完整的 B/S 架构应用：前端 Web UI + FastAPI 后端 + SQLite 数据库，共 7 大功能页面，通过 29 项自动化测试。数据采用 NASA C-MAPSS 公开数据集（4 个子集）。系统同时提供了离线单文件测试站（模型权重内嵌 HTML、浏览器本地推理、与 Python 数值误差 < 1e-5）与 GitHub Pages / Streamlit 云部署，任何电脑均可直接访问使用，实现了课程设计"数据 → 预处理 → 算法 → 系统 → 交付"的完整闭环。

一、项目背景与选题

工业设备（航空发动机、风机、机床等）的退化预测是制造智能的核心问题之一：通过传感器采集的工况数据，提前预测设备剩余寿命（Remaining Useful Life, RUL），支撑预测性维护决策。该类问题普遍存在小样本、高噪声、多工况等挑战，需要融合多种智能计算方法加以解决。

根据课程设计任务书，要求完成：选题说明与方案设计、数据来源与预处理、基于多种技术方向的完整演示系统（B/S 架构）、自动化测试、需求规格说明书、设计报告、答辩 PPT，以及 AI 使用（vibe coding）过程档案，并全程使用 Git 进行版本管理。本项目在此基础上进一步完成离线测试站与云部署，形成可在线访问的交付物。

二、总体方案与技术路线

系统按"数据层 → 算法层 → 服务层 → 表现层"四层架构组织，三大技术方向各司其职并形成业务闭环：

图 1：系统四层架构（B/S）

三大技术方向及其在系统中的落点：

  • 统计学习：数据清洗、IQR+Z-score 噪声识别、方差/相关/ANOVA 特征筛选、分段线性 RUL 标签、GroupKFold 交叉验证、标准化防泄漏。
  • 深度学习：双层 LSTM（窗口 30，hidden 96）时序回归预测 RUL，Adam + 权重衰减 + Dropout + 早停 + 学习率调度。
  • 智能计算优化：基于权重大小剪枝 + int8 模拟量化，在几乎不损失精度前提下显著压缩模型，适配普通 PC 部署。

五、算法模块设计

5.1 深度学习：双层 LSTM

LSTMRULModel:
  LSTM(input=15, hidden=96, layers=2, batch_first=True, dropout=0.2)
  Head: Linear(96→32) → ReLU → Dropout → Linear(32→1)
训练：Adam + 权重衰减 + SmoothL1(Huber) + ReduceLROnPlateau + 早停

滑动窗口构造时序样本（window=30, stride=1），每个样本为最近 30 个周期的特征序列，输出为该时刻的 RUL。预测时对输出做非负裁剪（clip ≥ 0）。

5.2 智能计算优化：剪枝 + 量化

  • 剪枝：基于权重大小（magnitude）对 LSTM/全连接层剪去 30% 权重，形成稀疏模型。
  • 量化：对剪枝后模型做 int8 模拟量化（quant_bits=8），显著降低存储占用。
  • 对比：在相同测试窗口上评估基准与优化后模型的参数、体积、推理耗时与精度。

八、测试与质量保障

自动化测试覆盖后端 API、服务层、数据库层与手动预测接口，共 29 项测试全部通过（backend/tests/ 四文件，一键 bash run_tests.sh）。

  • API 测试：数据集查询、模型查询、预测记录、在线预测、模型信息、手动预测接口（含参数校验：列数不匹配 400、空输入 400）。
  • 服务层测试：预处理流水线、特征筛选、模型训练/加载、剪枝量化对比。
  • 数据库测试：四表增查、预测记录写入。
  • 手动预测接口：模型信息返回特征列表 / 窗口 / 示例读数；手动预测数值与 Python 基准一致。

离线单文件测试站另通过 JS 与 Python 逐位对比：同一输入序列下 JS 推理 RUL = Python 参考值（误差 < 1e-5，float32 精度内一致）。
