# 云部署指南：完整版在线网站（Streamlit）

本仓库除本地 B/S 系统（FastAPI）与离线单文件测试站外，还提供 **`app_streamlit.py`** —— 复用全部后端业务逻辑（统计学习预处理 / LSTM 训练预测 / 剪枝量化优化）的 Streamlit 多页面完整版。部署到云平台后，**任何电脑打开网址即可使用，无需下载、无需安装**。

## 推荐平台：Streamlit Community Cloud（免费、免信用卡、用 GitHub 登录）

### 部署步骤（约 3 分钟）

1. 打开 **https://share.streamlit.io** ，点 **Sign up**，选择 **Continue with GitHub** 登录（授权你的 GitHub 账号）。
2. 登录后点 **New app**。
3. 填表：
   - **Repository**：选择 `wangyi051029/biji`
   - **Branch**：`main`
   - **Main file path**：`app_streamlit.py`
   - **App URL**：自定义，如 `rul-system`
4. 点 **Deploy**，等待构建完成（首次约 2~5 分钟，依赖包含 CPU 版 torch）。

部署成功后你会得到一个**固定网址**：`https://rul-system.streamlit.app`（或你填的名字），任何电脑/手机打开即可使用完整版 7 大功能：总览、数据管理、模型训练、智能优化、在线预测、手动测试、对比分析。

### 说明

- 仓库已内置：预处理后数据（`data/processed`）、原始数据（`data/raw`）、已训练模型（`data/models/FD001_LSTM.pt` 及优化版）、演示数据库（`data/app.db`），所以部署后**开箱即用**，无需等待训练。
- 训练 / 优化页面为可选操作（在云端 CPU 上约 20~60 秒），日常演示用内置模型即可。
- `requirements.txt` 中 torch 走 CPU index，构建体积小、速度快。

## 本地运行（可选，无需部署时）

```bash
pip install -r requirements.txt
streamlit run app_streamlit.py
# 浏览器打开 http://localhost:8501
```

## 备选平台

| 平台 | 说明 |
|------|------|
| Hugging Face Spaces | 用 GitHub 账号登录，选 Streamlit SDK，主文件填 `app_streamlit.py`，同样免费 |
| 自有云服务器 | `nohup streamlit run app_streamlit.py --server.port 8501 &`，配反向代理即可 |
